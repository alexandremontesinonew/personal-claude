🚀 COMO USAR

1️⃣ INSTALAÇÃO RÁPIDA (Windows):
   
   cd claude-desktop-automator
   setup.bat

2️⃣ MODO INTERATIVO:
   
   python -m claude_automator.cli interactive

3️⃣ MODO BATCH:
   
   python -m claude_automator.cli batch prompts.txt

4️⃣ PROMPT ÚNICO:
   
   python -m claude_automator.cli send "Explique Python"

5️⃣ USO PROGRAMÁTICO:
   
   from claude_automator import Automator
   
   with Automator() as auto:
       response = auto.send_with_retry("Hello!")
       print(response)
